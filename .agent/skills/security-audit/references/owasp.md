## OWASP Checklist

Walk the current OWASP Top 10 (access control, cryptographic failures,
injection, insecure design, misconfiguration, vulnerable components,
authentication and session failures, integrity failures, logging and monitoring
failures, SSRF) against routes, services, UI, storage, jobs, and integrations.
Multi-tenant boundaries, agent hooks, MCP configuration, and installer scripts
are in scope; `agent-surface.md` covers the agent-specific checks.
