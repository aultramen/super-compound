# /sc-launch Runtime Contract

Purpose: run the lifecycle from idea to verified delivery.

Run one active stage at a time: status, explore, conditional research, PRD,
plan, eval, `/sc-go` preview, work (including UI goals), review, audit,
`/sc-go` finish preview, compound. At each non-trivial boundary update
`docs/STATE.md` with only artifact path, decisions, blockers, verification, and
next route; `.continue-here.md` remains a short pointer. Release prior stage detail.
Return research to its decision owner. Skip only with evidence. Launch grants no
deploy, publish, commit, push, or PR permission.
