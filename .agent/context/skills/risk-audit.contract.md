# Risk Audit Skill Contract

Use before full risk skills.

- Scope security, compatibility, privacy, threat, and secure-code concerns.
- Inspect manifests, env examples, hooks, prompts, config, and affected source.
- Run safe read-only checks.
- MCP launch configs: classify selectors without executing launchers using `.agent/skills/security-audit/references/agent-surface.md`.
- Report confirmed findings, risks, and assumptions by severity.
